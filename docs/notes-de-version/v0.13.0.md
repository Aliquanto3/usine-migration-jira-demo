# v0.13.0 : interface à la charte générique v2.1

L'interface web passe à la charte générique v2.1 (dépôt `Aliquanto3/charte-generique`) : sombre d'abord, deux thèmes, bouton principal neutre, Sora pour les titres. Migration faite avec le skill `charte` (audit, plan de correspondances, application). Aucun changement fonctionnel.

## Contenu

- **Couleurs** : `cadre.css` ne contient plus de couleur en dur hors des deux blocs de variables, nommées comme les jetons de la charte. Chaque valeur vient d'un jeton v2.1. La table des correspondances appliquées est dans `DESIGN.md` (section Colors).
- **Thèmes** : le sombre est le thème par défaut. Le clair suit `prefers-color-scheme: light`. `data-theme="light"` ou `data-theme="dark"` sur `<html>` force un thème, pour les tests et les captures.
- **Boutons et liens** : bouton principal neutre (`bouton`, `sur-bouton`, survol `bouton-survol`), boutons secondaires en contour `trait-fort`, anneau de focus `focus`, liens toujours soulignés.
- **Statuts** : pastilles météo, bandeaux et badges par rôles (`succes`, `alerte`, `erreur`, `accent`), avec leur libellé.
- **Polices** : Sora 600 pour les titres, à la place de l'ancienne police de titres (`Sora-SemiBold.woff2` et sa licence OFL). Piles de repli de la charte.
- **Signature** : pictogramme et nom en Sora dans l'en-tête, favicon sur toutes les pages (y compris la page d'erreur d'un téléchargement), filet or sous le titre de chaque écran.
- **Tests** : `tests/unit/ui/test_charte.py` vérifie les contrastes des deux thèmes (4,5:1 pour 31 couples texte/fond, 3:1 pour le contour secondaire, le focus et le filet) et la présence de l'icône. `test_polices_et_licences_ofl` suit Sora.
- **Captures** : `docs/media/charte-v2/` (sept écrans, clair et sombre, 1280 px). Le README affiche la carte météo selon le thème de GitHub.
- **Docs** : `DESIGN.md` du dossier UX réécrit (frontmatter, Brand & Style, Colors, Typography) avec renvoi à la charte.

## Limites

- Pas de sélecteur de thème dans l'interface : le thème suit le système. À reprendre dans une story ultérieure.
- Le GIF du README (`docs/media/demo-agent.gif`) montre l'ancienne apparence. Il est à refaire ; le README l'a remplacé par une capture fixe.
- La capture de l'écran Pseudonymisation montre l'erreur « clé absente ou trop courte » : la clé factice de capture fait 15 caractères.
- Résidus de l'ancienne charte laissés en historique, hors périmètre : `docs/tests-manuels.md`, les notes de version antérieures, les maquettes (`mockups/`, `imports/maquette-canvas/`) et `review-accessibilite.md` du dossier UX.
- `src/usine/adaptateurs/llm/registre.py` : la mention de provenance du code est conservée (ce n'est pas la charte).
- Les captures de l'écran Chaîne sont en Mode repli : le bouton principal y est inactif.

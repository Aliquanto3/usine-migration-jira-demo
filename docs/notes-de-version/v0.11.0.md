Les cinq stories bonus rejoignent la version principale : un Modèle ML explicable à côté de la Baseline, un mode LLM local, une observabilité des appels LLM et une détection de doublons. Toutes sont désactivées par défaut ou sans effet sur la démo. Toutes les données sont fictives ou publiques.

## Contenu

- **Modèle ML validé sur données réelles (4.6)** : modèle LightGBM de prévision évalué sur le Public Jira Dataset, comparé à la Baseline (SM-8).
- **Facteurs explicatifs du Modèle ML (4.7)** : contribution de chaque variable à une prévision (`pred_contrib`).
- **Mode LLM local (6.12)** : fournisseur `llama-server` derrière le port `FournisseurLLM`, choisi par `config/llm.yaml`. Les tickets ne quittent pas le poste.
- **Observabilité externe (6.13)** : traces des appels LLM envoyées à Langfuse, pseudonymisées, activées seulement par `USINE_LANGFUSE`.
- **Détection de doublons (6.11)** : paires de tickets probablement en double, avec score et seuil, en ligne de commande.
- **Contrats 1.11.0** : `Tache.doublons`, `PaireDoublon`, `SortieDoublons`, ajout sans rupture.

## Installation

LightGBM et Langfuse sont dans le groupe optionnel `bonus` : `uv sync --group bonus`. Sans ce groupe, l'application et la démo fonctionnent comme avant.
